# Reyhan Asadella Zhafif — Junior Network Engineer Portfolio 🌐

A modern, high-performance personal portfolio website built with clean Vanilla HTML5, CSS3, and JavaScript. Designed specifically with a dark technical aesthetic tailored for **Network Infrastructure**, **Routing & Switching**, and **Server Administration**.

---

## 📌 About Me

I am a Junior Network Engineer focused on designing, configuring, and troubleshooting network infrastructure. Experienced in managing network hardware such as **MikroTik** and **Ruijie**, as well as administering services on **Linux (Debian/Ubuntu)** and **Windows Server** environments.

---

## 🛠️ Tech Stack & Architecture

- **Core:** HTML5, CSS3 (Custom Design Tokens), Vanilla JavaScript (ES6+)
- **Typography:** IBM Plex Mono & IBM Plex Sans (Google Fonts)
- **Icons:** Custom SVG Line Icons (Lucide-inspired)
- **Deployment Ready:** Vercel Optimized (`vercel.json`)

---

## ✨ Key Features

- **Interactive Network Topology Canvas:** Real-time HTML5 Canvas animation simulating network nodes, edge connections, and traveling data packets in the hero background.
- **Terminal CLI Simulator:** Typing effect simulating active network commands (`ping`, `ssh`, `traceroute`, `status`).
- **Bilingual Support (ID / EN):** Instant language switcher between Indonesian and English powered by a modular translation dictionary.
- **Scroll Reveal Animations:** Smooth IntersectionObserver-based entrance animations for section elements and skill cards.
- **Responsive Projects Carousel:** Touch/drag & button-navigated horizontal project carousel with dynamic dot indicators.
- **Contact Form Integration:** Built-in validation with graceful Formspree integration for direct email notifications.
